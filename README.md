# TemperatureConverter.cpp
A menu-driven C++ program that I made for my college Introduction to Programming course that converts temperatures between Celsius, Fahrenheit, and Kelvin. 
- Has four conversion options: Celsius to Fahrenheit, Fahrenheit to Celsius, Kelvin to Fahrenheit, and Fahrenheit to Kelvin
- Uses a 'switch' statement to route menu selections and perform temperature calculation
- Includes a 'default' case to handle invalid menu choices cleanly
